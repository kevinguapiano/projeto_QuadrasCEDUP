# projeto_QuadrasCEDUP
Sistema de reserva de quadras esportivas em Lages/SC, desenvolvido em Python/Flet (Web/Desktop). Projeto acadêmico do curso Técnico em Desenvolvimento de Sistemas no CEDUP, criado em conjunto com os alunos Kevin, Lucas e Pablo. Inclui busca, seleção de horários e gestão de agendamentos.
