## 🎯 Objetivo do Projeto

O **Quadra Search** foi criado para resolver um problema real identificado na cidade de Lages/SC: a dificuldade de agendar quadras esportivas por meio de chamadas telefônicas ou mensagens manuais[cite: 5]. 

A plataforma funciona como uma intermediária entre atletas e proprietários de espaços esportivos[cite: 5]:
* **Atletas / Jogadores:** Podem pesquisar quadras por modalidade, verificar horários disponíveis em tempo real e realizar agendamentos[cite: 5].
* **Gestores / Proprietários:** Podem cadastrar os seus espaços, gerir a grade de horários e acompanhar a ocupação da quadra[cite: 5].

---

## 🛠️ O que foi Desenvolvido (Recursos do Sistema)

- **Estudo e Modelagem de UX:** Pesquisa de mercado, benchmarking de soluções concorrentes e definição de personas e regras de negócio[cite: 5].
- **Interface Gráfica com Flet:** Desenvolvimento completo da interface em Python utilizando o *framework* Flet.
- **Execução Híbrida (Desktop e Web):** Suporte para rodar a aplicação como programa local ou diretamente no navegador via CLI do Flet.
- **Simulação de Banco de Dados e Sessão:** Estruturação em memória dos dados das quadras e das permissões de acesso (visitante, jogador e gestor).
- **Fluxo Completo de Reserva:** Telas interativas para login, busca de espaços, detalhes com seleção de horário e confirmação do agendamento.
